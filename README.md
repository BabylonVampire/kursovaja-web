# Диплом, что осталось реализовать

## Косметика

1. Накинуть гвардов
2. декомпозировать текстовый редактор
3. Общий рефактор

## Общее

1. Реализовать Галерею работ пользователя (Ok)
2. Реализовать возможность оставлять комментарии к работам
3. Реализовать систему с шаблонами стилей
4. Реализовать загрузку сохраненных работ (Ok)
5. Реализовать возможность студентам распределяться по вузам/группам, а преподавателю - закреплять за собой определенную группу
6. Реализовать возможность преподавателем создания единой темы для группы или отдельных студентов, чтобы облегчить процесс проверки работ
7. В рамках вышеописанной системы, реализовать наглядную демонстрацию, у кого что готово с возможностью открыть работу и оставить там комментарии

## Будет круто, если добавлю

2. Отправка заявок о закреплении на почту
3. Реализовать глобальный поиск по работам с флагом public
